# Course 2: Supervised Machine Learning - Regression

Folder ini berisi rangkuman materi, *hands-on lab*, kuis, dan proyek akhir untuk Course 2 yang berfokus pada pemodelan regresi dan teknik regularisasi.

---

## 📚 Rincian Modul

### Modul 1: Introduction to Supervised Machine Learning and Linear Regression
* **Topik Utama:** Pengenalan Supervised Learning, konsep dasar Simple & Multiple Linear Regression, Cost Function, dan Optimization (Gradient Descent).

### Modul 2: Data Splits and Polynomial Regression
* **Topik Utama:** Pembagian data (*Train/Test Split*), evaluasi *generalization error*, dan hubungan non-linear menggunakan *Polynomial Regression*.

### Modul 3: Cross Validation
* **Topik Utama:** Validasi silang (*K-Fold Cross Validation*, *Leave-One-Out*), pencarian parameter terbaik, dan estimasi performa model yang stabil.

### Modul 4: Bias Variance Trade off and Regularization Techniques: Ridge, LASSO, and Elastic Net
* **Topik Utama:** Penanganan *Underfitting vs Overfitting* (*Bias-Variance Dilemma*), serta teknik regularisasi L2 (*Ridge*), L1 (*LASSO*), dan kombinasi keduanya (*Elastic Net*).

### Modul 5: Regularization Details
* **Topik Utama:** Pendalaman eksekusi regularisasi, *hyperparameter tuning* (nilai $\alpha$ / $\lambda$), pemisahan fitur (*feature selection* via LASSO), dan efek scaling pada regularisasi.

### Modul 6: Final Project
* **Topik Utama:** Implementasi end-to-end pemodelan regresi, tuning regularisasi, dan evaluasi model pada dataset kasus nyata.
