# Pertemuan 1: Sejarah AI & Data Cleaning

## 🎯 Fokus Pembelajaran
Pada pertemuan pertama ini, pembelajaran difokuskan pada pemahaman konseptual tentang Artificial Intelligence (AI) modern dan langkah paling krusial dalam *pipeline* Machine Learning, yaitu prapemrosesan data (*Data Preprocessing*).

## 📝 Rangkuman Materi

**Modul 1: Sejarah Singkat AI Modern dan Aplikasinya**
- Memahami evolusi AI dari sistem berbasis aturan (*rule-based*) menuju sistem berbasis data (*data-driven*) menggunakan Machine Learning.
- Mengenal perbedaan antara Artificial Intelligence, Machine Learning, dan Deep Learning.
- Mengidentifikasi berbagai *use case* AI di dunia nyata, seperti sistem rekomendasi dan pengenalan gambar.

**Modul 2: Mengambil dan Membersihkan Data (Data Cleaning)**
- **Mengapa Data Cleaning Penting?** Kualitas model Machine Learning sangat bergantung pada kualitas data (*Garbage In, Garbage Out*). Data mentah di dunia nyata sering kali kotor, tidak lengkap, atau formatnya tidak konsisten.
- **Teknik Pembersihan Data Dasar:**
  - Menangani *Missing Values* (nilai yang hilang/NaN) dengan cara menghapus baris/kolom atau melakukan imputasi (mengisi dengan nilai rata-rata/median).
  - Menghapus data duplikat (*duplicate rows*).
  - Memperbaiki tipe data yang salah (misalnya, angka yang terbaca sebagai *string*).
  - Mengidentifikasi *outliers* (data pencilan) yang dapat merusak performa model.
